Test XLS Download Extension

Instructions:

  1. Make sure the "Replace and Download XLS" extension is installed and enabled
  2. Click one of the buttons below to generate and download a test Excel file
  3. The extension should automatically intercept the download and add "1" to column U header
  4. Check the downloaded file to verify the modification

Verification

Open the browser console (F12) to see verification results and run additional tests.

Available console commands:

  • verifyExcelModification() - Test the modification logic
  • generateTestFile() - Generate a test file to download
  • checkExtensionAPIs() - Check available Chrome APIs
